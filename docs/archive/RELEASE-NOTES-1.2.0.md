# AKVORIA ASE LOCAL 1.2.0

- Sınırlı aralıklı, yalnızca açıkça seçilen klasörleri izleyen dosya monitörü eklendi.
- Ed25519 imzalı SHA-256 tehdit beslemesini çevrimdışı içe aktarma modülü eklendi; sürüm geriye alma reddedilir.
- Dosya izleme kapsamı, sembolik bağlantı güvenliği ve geçersiz imza testleri eklendi.

Sınırlar: Bu izleme kernel seviyesinde gerçek zamanlı koruma değildir. Otomatik internet beslemesi yapılandırılmamıştır. Android/Windows gerçek cihaz doğrulaması kullanıcı testini gerektirir.
