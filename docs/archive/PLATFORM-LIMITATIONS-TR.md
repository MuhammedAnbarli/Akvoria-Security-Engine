# Platform sınırları

- Linux: Bu paket için otomatik testler Linux ortamında çalıştırılmıştır.
- Android/Termux: Yalnızca Termux'un erişebildiği dosyalar taranabilir. Android uygulama sandbox'ları aşılamaz. Arka plan çalışması Android pil/işlem kısıtlamalarına tabidir.
- Windows: Bu sürümde gerçek Windows cihaz testi yapılmamıştır.
- Gerçek zamanlı koruma: Bu sürümde dosya sistemi olaylarına dayalı tam zamanlı OS-geneli koruma bulunmaz.
- Kernel sürücüsü, davranışsal sandbox, otomatik ağ engelleme ve imzalı tehdit akışı sunucusu bulunmaz.
